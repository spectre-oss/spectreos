# Shabnam Font (v5.0.1, Without-Latin / WOL subset)

Used by the Bhoo Web App Debugger (`tools/bhoo-web-debug`) so Persian/Farsi text renders in **Shabnam** in the browser, matching SpectreOS's system font configuration (`codes/os/specrte-nix-f1/modules/fonts.nix` and `codes/apps/wisp/src/services/fonts.rs`).

- **Upstream**: Saber Rastikerdar — `shabnam-font` v5.0.1 (`https://github.com/rastikerdar/shabnam-font`)

  - `Shabnam-WOL.ttf` (weight 400)
  - `Shabnam-Medium-WOL.ttf` (weight 500)
  - `Shabnam-Bold-WOL.ttf` (weight 700)
