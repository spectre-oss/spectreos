## Applied guard

The installed logind default was `HandlePowerKey=poweroff`. Phosh and GNOME
media keys eventually acquire `handle-power-key` inhibitors, but a press before
that point triggers logind's default action. Set only `HandlePowerKey=ignore`;
Phosh retains normal short-press handling once its inhibitor exists. The
shutdown menu and hardware long-press behavior are not changed by this setting.

Live `/run/systemd/logind.conf.d/60-spectre-power-key.conf` was loaded with
`systemctl reload systemd-logind`; the D-Bus `HandlePowerKey` property reads
`ignore`. A persistent service pre-start drop-in under
`/etc/systemd/system.control/systemd-logind.service.d/60-spectre-power-key.conf`
recreates this runtime configuration on boot (the image's ordinary `/etc` is
read-only). The service manager parsed both pre-start commands successfully.
No logind/Phosh restart or second reboot was needed to apply the live policy.
Persistence has not yet been tested with another physical reboot.

Source `modules/phosh-console.nix` sets the equivalent NixOS logind option and
copies the configuration into stage-1 runtime storage for future boot-only
updates. Build-host Nix evaluation passed.
