# Android XML import into Bhoo

`tools/import-android-layout.py` compiles a deliberately explicit Android layout
subset into static Rust `bhoo::android_xml::Node` trees. The generated trees use
Bhoo drawing, input, semantics, text fields, state layers and scroll physics.
Anonymous child widgets receive stable path-derived IDs, including independent state for unnamed scroll views. There is no Android runtime, Java/Kotlin execution, React, or HTML widget layer.
The web host supplies canvas drawing and the platform text/IME adapter.

The [Android framework widget inventory](android-widget-inventory.md) lists the API 35 widget classes and their current XML importer status.
