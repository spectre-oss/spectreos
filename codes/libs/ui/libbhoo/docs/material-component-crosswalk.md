A local research snapshot is in ignored `context/material-design-guidelines`; do not redistribute its content or media without reviewing its terms.

Each row maps an official page to Bhoo’s design documents and existing Rust browser scenes. A scene demonstrates only the behavior listed in its document; **no row is certified complete**. Investigate each page’s variants, states, interaction, accessibility, responsive behavior and motion against the upstream implementation before marking it complete.
