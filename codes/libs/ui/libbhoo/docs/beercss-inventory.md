## Helpers, settings and JavaScript

The [helper modules](https://github.com/beercss/beercss/blob/47592ff1a644df437ebdf08c8dbdc967ed2e68db/docs/HELPERS.md), [settings](https://github.com/beercss/beercss/blob/47592ff1a644df437ebdf08c8dbdc967ed2e68db/docs/SETTINGS.md), and [JavaScript behaviors](https://github.com/beercss/beercss/blob/47592ff1a644df437ebdf08c8dbdc967ed2e68db/docs/JAVASCRIPT.md) require individual cross-platform review. Responsive CSS classes, browser selectors, dynamic theme extraction, color palettes, [wave feedback](components/hover-wave.md), ripple behavior, and rotation utilities are not automatically equivalent to Bhoo APIs.

All 37 source assets with path data are represented as sampled, tessellated Rust shapes; the two animated wave assets have initial motion implementations. The remaining animated loading SVG does not have a static path and remains open. The source also includes `wavy.svg` and `wavy-circle.svg`; the latter contains a hole. The full MIT license and upstream shape credits accompany the derived geometry.
